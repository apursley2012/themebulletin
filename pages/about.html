The collection

Built to Make Theme Browsing Easy

This gallery brings my standalone GitHub Pages portfolio themes into one organized place. Every theme keeps its own visual identity, live demo, source repository, and individual profile page.

How to use it

Browse, Compare, and Explore

  • Open a category board to compare related designs.
  • Select either the Polaroid or sticky note to open a theme page.
  • Use each profile page to launch the live demo or inspect the repository.

Created by

Alysha Pursley

I designed this collection as a professional showcase for a wide range of static portfolio concepts, from developer workspaces and retro interfaces to cosmic, colorful, and mystical themes.
