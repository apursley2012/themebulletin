Project case study

ThemeBulletin: Bringing 64 Portfolio Concepts Into One Browsable Collection

ThemeBulletin is a visual directory of independently published portfolio websites. The project turns a growing set of distinct designs into a single place where visitors can discover a style, inspect a preview, and move directly to the working site or its source code.

The challenge: a collection needs a clear point of entry

Each portfolio theme has its own look, navigation, and personality. That variety is valuable, but separate repositories and demo URLs make it difficult to compare designs or understand the breadth of the collection. ThemeBulletin addresses that discovery problem without replacing the individual projects.

The approach: organize by visual language

The directory groups 64 themes into four browsable collections: Retro Tech & Arcade, Cosmic & Celestial, Colorful & Creative, and Magical & Spooky. The corkboard, pinned notes, and Polaroid-style previews give the gallery a recognizable identity while letting each theme's screenshot remain the focal point.

Visitors can filter by category, move between boards of themes, and open a dedicated profile. Each profile provides a larger preview, a short design description, and direct links to the live demo and source repository. The category names and records are maintained in one JavaScript dataset, so navigation and board contents stay in sync.

Implementation: static by design

The catalog uses semantic HTML, page-specific and shared CSS, and lightweight JavaScript for filtering, pagination, and board scaling. The site is structured for GitHub Pages and does not require an application server, database, or build pipeline. Individual theme pages remain static documents, making their content accessible through ordinary links.

The outcome

The result is a unified entry point to 64 distinct portfolio concepts, with a consistent path from discovery to preview to source code. The gallery is intentionally a directory rather than a replacement for the linked projects: each theme keeps its own identity and can be explored independently.

Design notes

Behind the Collection

Two short articles on the design decisions that shape how the gallery works for visitors.

Why the Corkboard Works as Navigation

A theme gallery has to communicate variety without becoming a wall of identical cards. The corkboard borrows the familiar language of pinned ideas: a quick glance suggests exploration, comparison, and discovery. Sticky notes introduce categories and Polaroid-style images give the work itself a visual anchor.

The decorative approach is paired with conventional web navigation. Category controls are buttons, theme previews lead to real pages, and each detail page provides explicit links to the demo and repository. This separation matters: visual personality should support discovery, not make visitors guess what is clickable.

The square-board composition also introduces a responsive design tradeoff. Rather than rearranging each pinned item, the entire board scales uniformly on narrow screens. This preserves the arrangement while the surrounding page content reflows, although pinned text becomes smaller.

One Directory, Many Independent Projects

ThemeBulletin treats the collection and the themes as separate products. The directory is responsible for organization, previews, and wayfinding. Each standalone portfolio is responsible for its own content, visual system, and implementation.

This boundary keeps the catalog maintainable. A central theme record stores the display name, category, summary, preview image, profile path, demo URL, and repository URL. The gallery reads those records to build its navigation and theme cards, while the profile pages offer a consistent place to evaluate each design before leaving the directory.

For visitors, the benefit is straightforward: compare several creative directions in one interface, then open the exact project that interests you. For the collection, it creates a clear structure that can grow without flattening the differences between its themes.
